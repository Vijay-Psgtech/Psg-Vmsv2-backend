# PSG Visitors Management – Backend

This repository contains the **Express/MongoDB backend** for the PSG Visitors Management application.  
It exposes RESTful APIs for authentication, visitors data, hosts, security and admin dashboards.

## 📁 Project Structure

config/

Server.js

\`\`\`


## 🚀 Getting Started

### Prerequisites

- Node.js v16+  
- MongoDB (local or Atlas)  
- npm (comes with Node)

## 🛠 Core Features

- **Admin authentication & management**  
- **Visitors CRUD operations**  
- **Security tracking**  
- **Protected routes with JWT**

## 📦 Models

- **Admin** – admin users  
- **Visitors** – visitors records  
- **Security** – visitors entries
